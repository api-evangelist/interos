# Interos

> Interos operates an automated supplier-resilience platform that maps and continuously
> monitors extended supply chains, delivering real-time multi-domain risk scores and alerts.
> The Interos API (OpenAPI 3.0.2, REST/JSON) exposes organization search, organization and
> risk profiles, the supplier relationship graph, organization groups, custom fields, and
> scenario watchlists. Authentication is via two request headers: x-api-key (developer key)
> and x-customer-id (tenant scope). Generated by the API Evangelist enrichment pipeline.

## API
- [Interos API (OpenAPI 3.0.2)](https://api.interos.ai/external_open_api): 10 operations under /v1, base https://api.interos.ai
